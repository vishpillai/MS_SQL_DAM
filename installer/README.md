# SQL DAM - Windows MSI Installer Package

This folder contains the ready-to-deploy `.msi` Windows installer for **SQL DAM (Database Activity Monitor)**, featuring both the **Windows Background Service** and the **Native Windows Desktop Application**.

**Publisher:** Vishal Pillai · [pillaivishal91@gmail.com](mailto:pillaivishal91@gmail.com) · [LinkedIn](https://www.linkedin.com/in/vishal-pillai-dba/)

## File Contents

- **`SqlDam-Setup-v1.0.0.msi`**: The complete, self-contained Windows Installer package (~58 MB). Bundles:
  - **`SqlDam.Web.exe`**: The background Windows Service engine with the embedded SQLite database and activity collection.
  - **`SqlDam.Desktop.exe`**: The native Windows desktop client with navigation toolbar, WebView2 embedded dashboard, and system tray notifications.
  - **Shortcuts**: Automatically installs **Desktop** and **Start Menu** shortcuts for "SQL DAM Desktop".
- **`Install-SqlDam.bat`**: Helper batch script to install the MSI semi-attended with an installation log (`install.log`).
- **`Uninstall-SqlDam.bat`**: Helper batch script to cleanly remove the Windows Service, desktop application, and shortcuts.
- **`Build-Msi.ps1`**: Automated PowerShell script that publishes both projects and recompiles the `.msi` package using WiX Toolset (requires the `WixToolset.UI.wixext` and `WixToolset.Util.wixext` v4.0.5 extensions, installed once via `wix extension add -g WixToolset.UI.wixext/4.0.5` and `wix extension add -g WixToolset.Util.wixext/4.0.5`).
- **`Package.wxs`**: WiX source defining the product metadata, target directory (`C:\Program Files\SqlDam`), service registration/recovery, data directory, desktop executable, and shortcuts.
- **`Files.wxs`**: Manifest generated by `GenerateFiles.ps1` defining all bundled dependencies.
- **`SetupWizard.wxs`**: Collects the organization name, identifier, initial Super Admin email, and OIDC client settings in the MSI wizard.

## Service hardening

- **Account**: the service runs as `LocalSystem` for simplicity (no extra SQL login grants needed to use Windows-integrated authentication against monitored instances). It never accepts inbound network connections — the web UI binds to `127.0.0.1` only.
- **Crash recovery**: the Service Control Manager is configured to restart `SqlDam` automatically after the 1st, 2nd, and 3rd unexpected terminations (60s delay, failure count resets after 1 day of stability), so a transient fault never leaves an instance unmonitored for long.
- **Data at rest**: the Data Protection key ring that protects stored SQL login passwords is itself encrypted at rest using Windows machine-scoped DPAPI, not left as plain XML.
- **Data directory**: runtime data (SQLite database, Data Protection keys) is stored under `%ProgramData%\SqlDam`, not under `C:\Program Files\SqlDam`, per Windows guidance that Program Files should hold read-only program binaries. The MSI stores the data directory and bootstrap settings for the service; the client secret is protected with machine-scoped DPAPI at first service startup. Uninstalling leaves existing database/keys in place.

## How Clients Install and Access

Download the standalone MSI from the [latest SQL DAM GitHub release](https://github.com/vishpillai/MS_SQL_DAM/releases/latest/download/SqlDam-Setup-v1.0.0.msi). The MSI bundles the service and desktop client; the generated package does not need files from this source folder. The desktop client requires the Microsoft Edge WebView2 Runtime, which is preinstalled on most supported Windows systems but is not bundled in the MSI. Install the [Evergreen WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) if it is missing.

### Installation
1. For remote access, ensure the initial Super Admin account exists in your OIDC identity provider and have its HTTPS authority, client ID, and client secret ready. Leave OIDC and admin email blank for local-only access.
2. Run the downloaded `SqlDam-Setup-v1.0.0.msi` as Administrator.
3. In the wizard, enter your organization and identifier. For remote access, also enter the existing Super Admin email and complete OIDC client settings. The installer assigns the SQL DAM role; it does not create the external login. The client secret is protected with Windows machine-scoped DPAPI by the service.
4. The installer extracts all files to `C:\Program Files\SqlDam\`:
   - Registers and starts the background **SQL Database Activity Monitor** (`SqlDam`) Windows Service, with its data stored under `%ProgramData%\SqlDam`.
   - Installs the **SQL DAM Desktop** client.
   - Creates a **Desktop Shortcut** and a **Start Menu Shortcut** named **SQL DAM Desktop**.

### How Clients Access SQL DAM

1. **Option 1: Windows Desktop App (Recommended for Operators & Admins)**
   - Double-click the **SQL DAM Desktop** icon on your Desktop or Start Menu.
   - Launches a native Windows desktop application window hosting the SQL DAM Control Plane.
   - Includes quick navigation buttons (Dashboard, Activity, Alerts, Sources, Audit Trail), a live service health monitor, and auto-minimizes to the Windows System Notification Area (Tray).
2. **Option 2: Web Browser**
   - Open any browser and navigate to:
     ```
     http://127.0.0.1:5055/
     ```
   - Accessible locally or via enterprise intranet reverse proxy.
